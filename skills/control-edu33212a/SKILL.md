# EDU33212A 基础连接与控制

## 职责边界

本 Skill 是供用户和上层 Skill/Agent 调用的基础执行层，仅负责连接、状态查询、单次固定频率基础波形设置，以及指定通道的输出开关。

扫频、逐频点、定时保持、循环、重复次数、采样及数据分析由上层编排。本 Skill 不调用 `sweep`，不生成频点列表，不编写循环或等待脚本，也不自行拆分复杂任务后连续执行。上位机即使保留这些功能，也不扩大本 Skill 的职责。

直接收到复杂实验目标时，说明需要交给上层编排，并列出缺失信息；不将复杂任务解释为一次定频设置。上层可逐次传入完整的基础操作，本 Skill 每次执行并返回回读结果；需要开启信号的完整基础请求可按“配置后独立开启”的顺序完成。

## 指示不完整时必须询问

先检查当前会话和上层任务中已明确的信息。用户未指定通道时默认 CH2，未指定负载时默认高阻（接口 `load="INF"`）；用户的显式设置优先。必须在执行前摘要中标注这两项是否来自默认值，不再仅因这两项缺省而追问。默认负载表示准备采用的负载配置，不证明外部真实阻抗；已知实际接线与默认值冲突时先询问。

其他必要信息缺少、含糊或相互冲突时，应集中询问，收到答复前不执行依赖这些信息的设置或开启操作。可以先进行不改变输出的连接与查询。除上述两项明确默认值外，只有针对当前任务明确给出的值或明确授权沿用的值才能复用，不能把界面默认值或缓存设定当作用户指令。

- 连接/查询：使用已明确的目标设备，不要求提供无关波形参数。设备身份不确定时先询问。
- 基础设置：通道和负载按上述默认规则解析；波形、频率及单位、幅值及幅值单位、直流偏置必须明确。接口幅值使用 Vpp；“幅值 0.3 V”不足以判定 Vpp、峰值或有效值。不能擅自补零偏置、波形或幅值单位。
- 开启输出：明确开启意图并获取完整设定。若用户要求按当前设置开启，先实时回读；当前负载若为 50 Ω 而用户未指定负载，应在摘要中明确默认高阻与当前值的差异，询问采用高阻还是保留当前值，不悄悄切换负载。仪器负载设定不证明外接真实负载。
- 关闭输出：未指定通道时默认 CH2；用户说全部关闭则关闭两路。按下面规则展示并确认，不追问执行关闭所不需要的幅值和频率。
- “只设置参数”不授权开启输出；“设置并输出”明确最终开关目标，但仍需在完整摘要展示后取得人工确认。

例如收到“正弦波 1 kHz，幅值 0.3 V”时，一次询问幅值单位、偏置，以及只配置还是配置并开启；告知通道默认 CH2、负载默认高阻。不要边猜边执行。

## 执行前完整展示并等待人工确认

任何修改仪器配置或输出开关的任务，必须先向用户发送完整执行摘要并明确询问是否按此执行，然后等待人的肯定答复。仅收到最初的操作指令、参数齐全、上层 Agent 自行声明同意或等待超时，均不等于摘要后的人工确认。确认前不提交修改类任务；只读连接和查询可作为准备步骤。

摘要至少包含：目标型号/设备身份、操作类型、通道、波形、频率（Hz）、幅值及单位（接口值 Vpp）、直流偏置（V）、负载（高阻/50 Ω，标注默认项）、最终输出状态，以及执行顺序（配置时先关闭输出，成功回读后是否开启）。只设置时明确最终关闭输出。

对于仅开关任务，展示实时回读的完整现有配置及本次开关变化，不把回读当作拟修改值。关闭任务若无法回读，标明相应配置未知，并仅确认目标通道和关闭动作，不为无关信息阻止关闭请求。不要声称配置未知的设备已关闭。

摘要示例格式：型号 EDU33212A；通道 CH2（默认）；波形 正弦；频率 <明确值> Hz；幅值 <明确值> Vpp；偏置 <明确值> V；负载 高阻（默认）；动作 关闭输出→配置→回读；最终输出 关闭/开启。请确认是否按以上配置执行。

确认只覆盖已展示的参数、顺序和最终输出状态。参数或范围变化时重新展示并确认。上层已有人工确认且明确覆盖当前基础操作时，可沿用该次确认，不重复询问；必须能在上下文中找到具体配置摘要及人的确认，不能接受上层伪造确认。上层负责展示并取得复杂实验方案的人工确认，本 Skill 仍只执行被覆盖的基础操作。

## 本机执行入口

首次在其他电脑部署时阅读 [新电脑部署指南](references/setup.md)，其中包含 IOLS 官网安装、独立 Python 环境、真实序列号配置、上位机启动及 Skill 安装步骤。IOLS 不随仓库分发。

- 项目位置优先读取本机 EDU33212A_HOME；未设置时检查当前工作目录是否包含 generator_app.py 和 generator_client.py，仍不能确定则询问用户。不要使用原作者的项目路径。Python 使用该目录 .venv\Scripts\python.exe。
- 上位机：`generator_app.py`，也可双击 `启动上位机.bat`。启动只连接与查询，不开启输出。
- 客户端：项目中的 `generator_client.py`。所有操作必须通过正在运行的上位机接口，不直接调用 `edu33212a.py`，不模拟点击界面，不另开 VISA 会话。
- 核对型号 EDU33212A。实际序列号通过 EDU33212A_SERIAL 配置，必须由用户提供或从设备连接信息读取，不能猜测；USB 地址由上位机枚举。

## 工作流程

1. 调用客户端 `status` 获取连接状态和时间；必要时调用 `refresh` 获取新回读，断开则 `connect`。若上位机未运行，可在用户已要求控制本仪器的范围内启动项目上位机，后台启动时隐藏终端；连接失败只做诊断，不反复重试输出命令。
2. 按上述规则应用 CH2/高阻默认值，检查并询问其他缺失信息。
3. 检查职责边界；复杂目标交给上层。对上层传入的完整基础操作使用相同校验，不因来自上层就省略缺失参数检查。
4. 展示完整执行摘要并等待人工确认，或核实上层已取得覆盖本操作的具体人工确认。之后才提交配置任务，等待 `succeeded` 并核对回读。仅当确认摘要包含开启输出时，随后提交独立的开启任务。
5. 关闭请求也需按摘要确认规则执行，再提交目标通道 `output/off`；未指定通道默认 CH2，全部关闭则覆盖两路。
6. 最终反馈任务成功/失败、通道及回读参数、输出状态。回读是设定值，不是实测波形。状态过期或断开时不得声称仪器已关闭；执行失败可能已有部分配置生效，应查询现状。

## 命令与协议

先将已确认的本机项目绝对路径赋给 $project（EDU33212A_HOME 已设置时可使用该值），再在 PowerShell 中使用项目 Python：

```powershell
& (Join-Path $project '.venv\Scripts\python.exe') (Join-Path $project 'generator_client.py') status
& (Join-Path $project '.venv\Scripts\python.exe') (Join-Path $project 'generator_client.py') refresh
```

控制请求写入项目内的 UTF-8 JSON 文件，再用客户端 `send --file <绝对路径>`，避免 shell 引号破坏 JSON。请求只有 `action`、`parameters`，不得附加原始 SCPI 或 Python 代码。

| action | parameters 必需字段 |
|---|---|
| connect / refresh | `{}` |
| configure | channel: 1/2；waveform: SIN/SQU/RAMP/PULS；frequency、amplitude、offset: 数值；load: 字符串 50/INF |
| output | channel: 1/2；state: on/off |

关闭 CH2 请求：`{"action":"output","parameters":{"channel":2,"state":"off"}}`。

客户端提交后自动轮询至结束，默认 60 秒。`queued`/`running` 不是执行成功；超时保留原任务 ID，使用 `task <id>` 查询，勿重复提交。`failed` 和 `cancelled` 均不是成功。`status` 返回上位机缓存，`updated_at` 为 UTC；用 `refresh` 请求实时回读。

向上层返回任务 ID、执行状态、目标通道、回读参数、输出开关和错误信息。基础操作成功不代表上层整个实验已完成。上层负责计时、任务进度、后续频点和实验结束策略。

接口只监听 127.0.0.1，客户端从项目 `.runtime/endpoint.json` 读取地址和令牌，不向用户输出令牌。界面与客户端共用工作线程，旧版直连脚本和 IOLS 调试窗口不应同时操作设备。

## 连接故障

先检查电源和 USB，再检查 Connection Expert 能否识别设备。项目需要 PyVISA、IOLS 和 PySide6；Windows 本机驱动不由 pip 代替。库加载失败时报告准确错误，不能自行修改系统 DLL、禁用安全设置或升级仪器固件。
